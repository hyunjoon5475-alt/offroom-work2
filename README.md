# OFFROOM 랜딩페이지

## 실행 방법
1. 이 폴더의 파일을 모두 같은 폴더에 둡니다.
2. `index.html`을 브라우저에서 열거나 VS Code의 Live Server로 실행합니다.
3. 랜딩페이지의 `서비스 미리보기` 링크는 `app.html`로 이동합니다.

## 파일 구성
- `index.html`: OFFROOM 소개 랜딩페이지
- `landing.css`: 랜딩페이지 스타일
- `landing.js`: 랜딩페이지 메뉴 및 인터랙션
- `app.html`, `app.js`, `style.css`, `native-bridge.js`: 서비스 미리보기용 프로토타입

※ 앱 프로토타입은 소개용 시연 화면입니다. 실제 사용 기록 연동이나 서버 저장 기능이 구현된 서비스는 아닙니다.
